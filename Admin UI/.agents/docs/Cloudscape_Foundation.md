# AWS Cloudscape Design Foundation Resources

## Foundation Topics
Read about these principles at `https://cloudscape.design/foundation/` (and its specific sub-pages):
- **Colors**
- **Content density**
- **Data visualization colors**
- **Design tokens**
- **Iconography**
- **Layout**
- **Motion**
- **Spacing**
- **Theming**
- **Typography**
- **Visual context**
- **Visual modes**
- **Visual style**

## Components
For specific UI component implementations (HTML/CSS structures, API, and usage), check the official GitHub repository:
- **Components Repo**: https://github.com/cloudscape-design/components

## Patterns
For larger page layouts and recurring UX solutions, check the patterns documentation:
- **Patterns**: https://cloudscape.design/patterns/

**Agent Instruction:** If you are unsure how to implement a specific UI element (e.g., a table, a metric card, spacing, or typography), you are required to fetch and read the relevant Cloudscape URL or GitHub repository to ensure the component strictly follows the AWS design system.
